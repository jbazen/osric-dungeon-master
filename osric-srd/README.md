# OSRIC SRD

This directory will hold the OSRIC rulebook converted from PDF to Markdown, one file per section,
for use as a rules-lookup reference by Claude (see the table in `../CLAUDE.md`).

## Status

Not yet populated. The conversion is being done separately from the official OSRIC PDF; once
finished, the Markdown files will be added here under `markdown/` using the same section naming
as the reference table in `CLAUDE.md` (e.g. `02 ability scores and races.md`,
`17a monsters statistics men demi-humans.md`, etc.).
